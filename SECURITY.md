# Security

Atlas is wander wildwood's fork of CoMaps for E Ink phones. Report a security problem in it to
email@wanderthe.dev. Please leave out anything that identifies a person, and any places or
routes of your own.

Atlas is signed with its own key, not CoMaps'. CoMaps does not support this fork; a problem in
CoMaps' own code, which Atlas carries, can also go to CoMaps, as the SECURITY.md in their
repository describes.
